# Python Training

Practice code and examples covering Python fundamentals, core skills, advanced concepts, and regular expressions.

## Topics Covered

- **Python Basics**: Introduction, variables and data types, operators, strings, conditionals, loops, lists, tuples & sets, dictionaries, functions, `*args` and `**kwargs`, modules, and exception handling.
- **Core Skills**: File handling, handling CSV and JSON, Object-Oriented Programming (OOP), pip & requests, and unit testing.
- **Python Advanced**: Decorators, functional programming concepts, generators, iterators & enumerate, lambda functions, map/filter/reduce, and recursion.
- **Pythonic Code**: Pythonic loops, enumerate & zip, comprehensions, advanced f-strings, and modern features.
- **Regular Expressions**: Pattern matching with `re` module (search, findall, sub, email/phone extraction).
